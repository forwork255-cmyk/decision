# Security

This skill contains no executable code — no `scripts/`, no dependencies, nothing that runs on its own. It is a set of Markdown instructions that a compatible AI agent reads and follows. The attack surface is limited to what the host agent's own tools (web search, file access, etc.) already expose.

If you find a way this skill's instructions could be manipulated into unsafe behavior (e.g. prompt injection through research results that gets treated as instructions rather than data), please open an issue.
